# Utility Token Prototype

## Working name

**Machine Commerce Proof Token**

Ticker in the prototype: **MPRF**.

This is a working identifier only. Check name/ticker availability and legal classification before deployment.

## Proposed supply

1,000,000,000 MPRF fixed supply.

No mint function after deployment.

## Intended utility

Potential future uses:

- service-credit discounts
- API quota boosts
- agent verification bundles
- developer grants
- protocol participation

## Deliberately excluded

- guaranteed returns
- dividend/revenue-sharing promises
- algorithmic “number go up” mechanics
- treasury trading by autonomous agents
- buyback/burn promises tied to price
- hidden minting powers

## Suggested allocation (illustrative)

| Bucket | % | Release logic |
|---|---:|---|
| ecosystem/developer rewards | 40% | usage/contribution-based, time-released |
| treasury | 20% | multisig + long timelock |
| grants/partners | 15% | milestone-based |
| team | 15% | 4-year vesting |
| community | 10% | contribution campaigns |

Do not sell these allocations to the public until legal review is complete.
