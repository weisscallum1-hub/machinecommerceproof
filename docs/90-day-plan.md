# 90-Day Build-and-Revenue Plan

## Phase 1: Proof of usefulness (days 1-14)
- Free scanner and proof endpoint.
- Publish 3 demos.
- Run 30-50 prospect scans.
- Sell first audits manually or through a simple checkout.
- Measure which findings cause buyers to pay.

## Phase 2: Agent-native monetization (days 15-30)
- Add an x402-gated deep verification endpoint.
- Publish service metadata and machine-readable documentation.
- Submit to relevant public catalogs/directories.
- Track paid calls, repeat callers and successful proof generations.

## Phase 3: Recurring revenue (days 31-60)
- Hosted receipt history.
- Monitoring and alerts.
- Customer-specific verification pages.
- Paid remediation templates.

## Phase 4: Network effects (days 61-90)
- ERC-8004-compatible identity/reputation hooks.
- Public verification directory.
- Reputation signals based on observed operational facts rather than opaque model scores.
- Third-party integrations.

## Kill/shift rules

Shift the positioning when three consecutive review cycles show that customers do not pay for proof/verification. Preserve the receipt engine as an infrastructure component and test an adjacent wedge such as agent security evidence, payment reconciliation, or machine-service discovery.
