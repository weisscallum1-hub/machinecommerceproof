# Autonomous Operating Architecture

## Core loop

Scout -> Analyze -> Build -> Measure -> Decide -> Repeat.

## Agents

1. Scout: watches protocol repositories, official specs and public ecosystem endpoints.
2. Readiness: evaluates public service surfaces for machine readability, identity, payment and proof hooks.
3. Lead Finder: produces research leads; never contacts prospects automatically.
4. Proof: produces signed, hash-linked execution receipts.
5. Revenue: summarizes product revenue events; never moves funds.
6. Content: drafts factual material; publication should remain gated.
7. Health: monitors endpoints and latency.
8. Strategy: converts metrics into a weekly product decision memo.
9. Risk Gate: flags actions that must stay human-approved.

## Why separate agents

Separating discovery, execution, measurement and decision-making prevents a single prompt or model error from becoming an autonomous commercial action.

## Human gates

Keep explicit human approval for token issuance/public sale, legal representations, custody, material spending, public financial claims, and outbound sales messages.
